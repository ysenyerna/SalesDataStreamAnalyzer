## Java Sales Data Analyzer
Simple app using Java streams to demonstrate data analysis of a CSV file.
### Instructions
Open the program with the terminal and run the commands `javac Main.java` and `java Main`
### Explanation
This project uses a CSV file named `sales.csv` which contains sample data for customer sales, including sale ID, employee name, region, and dollar amount. 
This program reads that data, stores it in a list, then performs various functions using Java streams to analyze the information. These include identifying highest and lowest sale, 
total amount from all sales, and sorting sales by region among others.
